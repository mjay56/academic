# Minje Kim — Academic Homepage

A restrained personal academic website for GitHub Pages.

## Structure

- `index.html` — intro page only
- `cv.html` — CV page
- `research.html` — placeholder page
- `project.html` — placeholder page
- `archive.html` — placeholder page
- `style.css` — shared styles
- `script.js` — footer year update

## Design direction

- English (UK style)
- Times New Roman typography
- dark indigo background with bright navy text
- simple daisy illustration on the intro page
- minimal academic navigation

## Publishing

Upload all files to the root of the `academic` repository and enable GitHub Pages from the `main` branch, root folder.
