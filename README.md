An understated, English-only academic homepage for Minje Kim, an M.A. student in International Commerce at Soongsil University.

## Design

- Palette: ivory and navy.
- Language: British English (`en-GB`); no Korean-language toggle.
- Typography: `Cambria Math` first, with Cambria, Constantia, Georgia and other serif fallbacks. The font installed on the visitor's device determines what is displayed; **no licensed font files are bundled**.
- Illustration: a single lightweight geometric SVG. No photographs, external image URLs, emojis or icon libraries.
- Responsive layout: desktop, tablet and mobile.
- No frameworks, packages or build step required.

## Publish to GitHub Pages

The intended repository is `https://github.com/mjay56/academic`, leaving the existing `mjay56.github.io` gallery untouched.

1. Extract this archive.
2. Upload the files **inside** this folder (`index.html`, `style.css`, `script.js`, `.nojekyll`, and optionally `README.md`) to the root of the `academic` repository.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then `main` and `/(root)`.
5. After publication, the site should be available at `https://mjay56.github.io/academic/`.

The site is not automatically uploaded or published by this archive.
